# App Store 物料

## 每种图的任务

| 图片 | 怎么做 |
| --- | --- |
| 产品页标题横图 | 用产品名和一句主张建立辨识度。先按该展示位置的安全区排文字和产品主体，再把背景延伸到画布边缘。 |
| 搜索结果横图 | 用短标题说明核心用途。可用大单机，也可用两张有关联的界面围住标题。安全区内要能看到标题和读懂主张所需的 UI。 |
| 竖版第 1 张 | 优先把核心体验讲清。用可独立读懂的真实界面和简短标题，在商店缩略图大小下先验一遍。 |
| 后续竖版 | 根据功能选用动作与结果连页、单页特写或双机层级。连页可以共用背景和设备对齐线，每张保留自己的语义。 |

例如菜谱 App，第 2 张可以在筛选结果里露出「番茄炖豆」，第 3 张接同一道菜的食材和步骤。两个标题分别讲「找到」和「开始做」，排在一起有连续性，单独出现也看得懂。

## 本地化与交付

- 先拿字最宽、构图最紧的一页试排。文案与手机内的语言、地区习惯和数据一致。短句在当地语言里按语义折行；竖排等语言特有的排法可替换成适合该语言的等效布局。
- 分别检查标题图与搜索图的安全区。把框叠在全幅上，再单独看框内和商店预览缩略图。输出成图移除辅助线。检查标题、手机与图形在实际裁切后的相对位置。
- 上架前按本次提交入口、设备组和地区核对尺寸、文件类型、透明通道和素材顺序。用户原图的像素尺寸可与成图要求不同。核对 [Apple 创意素材规范](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications/)与[截图规格](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/)。
