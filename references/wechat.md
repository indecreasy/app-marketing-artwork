# 朋友圈与微信群物料

| 场景 | 怎么做 |
| --- | --- |
| 朋友圈封面 | 内容顺序通常是产品名、核心主张、典型界面、行动入口。需要扫码时，把对应渠道的官方徽标、二维码和简短说明放在方形预览能看全的区域。 |
| 朋友圈功能图 | 每图讲一个场景。正文小一档，实际用法比功能名更容易懂。图片之间可换深浅、焦点与手机进画位置。 |
| 朋友圈方形预览 | 对照完整竖图和中心方形裁切，在手机大小检查标题、必要 UI 与下载区。让可裁切的辅助画面延伸到四周。 |
| 群聊长图 | 从最终单图按确认的顺序拼。封面可独占一行，后面的功能图用一列或两列。两列缩到实际手机宽度后，标题应仍能扫读。 |

先确认比例和张数，再定输出尺寸。用高质量原图导出以便后续平台压缩。检查实际导出图的二维码静区与目标地址，按近似手机宽度压缩后重扫。如果只更新部分图，确认长图是否也在本次交付范围，并在需要时同步。
